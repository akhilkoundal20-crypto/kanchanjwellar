# Kanchan Jewellers - Dari, Dharamshala

A luxury, mobile-responsive jewellery showroom website for **Kanchan Jewellers**, Dari, Dharamshala, Himachal Pradesh.

> “QUALITY JEWELLERY & UNMATCHED PRICES!”

## Features
- **916 Hallmark Gold Jewellery** showcase & details
- **92.5 Italian Silver Jewellery** collection
- **Certified Diamond Jewellery** & solitaire rings
- **Royal Bridal Collection** & consultation booking
- **Interactive Product Modal** with purity, weight, and care specifications
- **Real-time Search Modal** across all categories
- **Interactive Wishlist Drawer** with 1-click WhatsApp inquiry of all saved items
- **Direct WhatsApp & Phone Integration** for instant customer support
- **Google Maps Showroom Location** in Dari, Dharamshala
- **Framer Motion Animations** & luxury emerald/gold styling
- **Fully Responsive** (optimized for mobile 2-column layout, tablet, and desktop)

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
